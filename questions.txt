Q: Which core library is necessary for styling components in a modern generic React ecosystem?
- Tailwind
- Emotion
- Vanilla CSS
- Styled-Components
A: Vanilla CSS

Q: What is the primary purpose of ReactDOM in a React application?
- Managing global state
- Connecting React components to the browser DOM
- Handling HTTP requests
- Parsing Markdown files
A: Connecting React components to the browser DOM

Q: Which hook is used to perform side effects in functional components?
- useState
- useEffect
- useReducer
- useMemo
A: useEffect

Q: What does the term "glassmorphism" refer to in Web Design?
- Creating 3D models with WebGL
- A UI trend featuring frosted glass-like translucent effects
- Morphing SVG animations
- CSS Grid based masonry layouts
A: A UI trend featuring frosted glass-like translucent effects

Q: Which command creates a standard static production build with Vite?
- npm run start
